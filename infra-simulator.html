How the fleet is operated

      

        
15 sends per mailbox per day
A hard ceiling, not an average. Volume grows by adding mailboxes, never by pushing an existing one harder.

        
3 mailboxes per domain
Enough to make a domain worth the setup, few enough that losing one domain removes only 45 sends a day.

        
SPF, DKIM and DMARC on every domain
Authentication is set at purchase, before the first send. An unauthenticated domain is a burnt domain.

        
One identity across the fleet
Every mailbox signs as the same person, so a prospect who replies twice from different sequences meets the same name.

        
Rotation, not repetition
Sends are spread across the fleet and across the day. No prospect is ever contacted by two mailboxes on the same domain.

        
Replies land in one place
All mailboxes forward to a single monitored inbox. The client answers from one screen, not thirty-nine.
